# AQIL Smart Life — Flutter Mobil Ilovasi

**Toshkent Menejment va Iqtisodiyot Instituti (Farg'ona kampusi)**  
**Muallif:** 1-bosqich talabasi Sharofiddinova Nozima Egamberdi qizi  
**Yil:** 2026-yil | **Hudud:** Farg'ona shahri

---

## 📱 Loyiha haqida
Ushbu papkada loyihaning to'liq **Flutter (Dart)** kodlari joylashtirilgan.
Ilova Material 3 dizaynida, o'zbek tilida va quyidagi 5 ta asosiy bo'limdan iborat:
1. **Asosiy (Home):** Jonli GPS xaritasi, faol buyurtma, 4 xonali PIN kod, tezkor xizmatlar.
2. **Xizmatlar (Services):** Bolalar taksisi, enaga, maishiy ta'mir, avto SOS, ro'zg'or.
3. **Aqlli Uy (Smart Home):** Chiroqlar, aqlli eshik qulfi, harorat boshqaruvi, datchiklar.
4. **Moliya (Finance):** Nozima Sharofiddinovaning iqtisodiy-moliyaviy hisob-kitoblari va zararsizlik slayderi.
5. **Titul (Profile):** TMII rasmiy rekvizitlari va loyiha bayoni.

## 🚀 Qanday ishga tushiriladi va APK olinadi?

### 1. Dasturni ishga tushirish (Run):
```bash
cd flutter_aqil
flutter pub get
flutter run
```

### 2. APK chiqarish (Build APK):
```bash
flutter build apk --release
```
Tayyor APK fayl quyidagi manzilda hosil bo'ladi:
`build/app/outputs/flutter-apk/app-release.apk`
Uni to'g'ridan-to'g'ri istalgan Android telefonga o'rnatish mumkin!
